# Ollama Tools

Self-hosted tools that give [Ollama](https://ollama.com) models, and any other AI that can make HTTP requests, access to live data they don't have on their own.

| Project | What it is |
|---|---|
| [**Ollama-Tools-API**](Ollama-Tools-API/) | A small HTTP API for web search, weather, time, geolocation, crypto prices, network diagnostics and developer utilities, built to plug into Ollama's native tool calling. |

Each project has its own README with setup steps. For a full bot built on top of this, see [Nocturnal](https://github.com/Gigg1E/Nocturnal-ai).
